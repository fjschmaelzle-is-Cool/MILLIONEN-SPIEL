# Wer wird Opa-när?

Familien-Quiz zu Opas 77. Geburtstag – mobile Web-App (installierbar), 15 Fragen, Joker, Gewinnleiter mit echten Familien-Preisen, Wochen-Ranglisten, Duelle, Urkunden und Admin-Bereich.

Einrichtung und Regeln: siehe [ANLEITUNG.md](ANLEITUNG.md).

Schnellstart (Demo-Modus, lokal):

```
python -m http.server 5177
```
Dann http://localhost:5177 öffnen (Familien-Code `OPA77`).
